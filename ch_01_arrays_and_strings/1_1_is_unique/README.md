# 1.1 Is Unique

**Problema:**
Implement an algorithm to determine if a string has all unique characters. What if you cannot use additional data structures?

**Estrutura:**
Este pacote implementa as soluções em Rust para a questão. Foi criado isolado para facilitar integração direta no repositório `CtCI-6th-Edition`.

## Como testar localmente

```bash
cargo test
```
